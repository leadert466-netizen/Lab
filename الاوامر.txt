### المجموعة الأولى: تثبيت Flutter وضبط المسار بشكل دائم
تُستخدم لتنزيل فلاتر وتأكيد تثبيت مساره داخل التيرمينال:

```bash
# تنزيل فلاتر داخل بيئة العمل
git clone https://github.com/flutter/flutter.git -b stable

# تثبيت مسار فلاتر نهائياً في التيرمينال
echo 'export PATH="$PATH:/workspaces/Lab/flutter/bin"' >> ~/.bashrc && source ~/.bashrc

# التأكد من سلامة التثبيت وإصدار فلاتر
flutter doctor

```

### المجموعة الثانية: إدارة والتنقل بين المشاريع

تُستخدم للتحرك داخل المجلدات أو إنشاء مشروع جديد:

```bash
# إنشاء مشروع فلاتر جديد
flutter create lab_mohamed

# الدخول لمجلد المشروع للبدء في العمل
cd lab_mohamed

# الرجوع للمجلد الرئيسي السابق
cd ..

```

---

### المجموعة الثالثة: تشغيل التطبيق ومعاينته

تُستخدم لتشغيل كود الفلاتر وعرض الواجهة في المتصفح:

```bash
# تشغيل التطبيق سيرفر ويب على البورت 8080
flutter run -d web-server --web-port 8080

```

---

### المجموعة الرابعة: إضافة مكتبات الربط مع الـ API

تُستخدم لتنزيل حزم فلاتر الخاصة بالتعامل مع البيانات والإنترنت:

```bash
# إضافة مكتبة HTTP للتعامل مع الـ APIs
flutter pub add http

# جلب وتحديث كافة المكتبات الموجودة في مشروعك
flutter pub get

```

---

### المجموعة الخامسة: حفظ الشغل ورفعه على GitHub

تُستخدم قبل قفل الجهاز لضمان حفظ كل التعديلات على حسابك:

```bash
# تجهيز كافة الملفات والتعديلات للحفظ
git add .

# تسجيل نقطة حفظ مع كتابة وصف مختصر
git commit -m "Save work"

# رفع التغييرات لمستودع GitHub
git push origin main

```
